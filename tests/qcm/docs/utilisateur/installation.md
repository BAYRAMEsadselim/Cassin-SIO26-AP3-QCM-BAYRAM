# Installation (guide utilisateur)

La plateforme est installée par l'équipe technique. Pour l'installer sur un poste de développement, suivre [docs/technique/installations.md](../technique/installations.md).

## Se connecter

1. Ouvrir l'adresse de la plateforme dans un navigateur.
2. Saisir votre adresse e-mail et votre mot de passe, fournis par l'administrateur.
3. Vous arrivez sur la page d'accueil de votre rôle (administrateur, formateur ou étudiant).

En cas d'oubli de mot de passe, demandez à l'administrateur d'en définir un nouveau.
