# Manuel de l'administrateur

Ordre conseillé pour préparer une année, car chaque étape dépend de la précédente.

## 1. Créer les matières

Menu **Matières**, bouton « Nouvelle matière ». Une matière **affectée** (à un formateur ou à une classe) ne peut plus être modifiée ni supprimée.

## 2. Créer les comptes

Menu **Comptes**, bouton « Nouveau compte » : nom, prénom, e-mail, rôle (administrateur, formateur, étudiant) et mot de passe de 8 caractères minimum. Pour changer un mot de passe, modifier le compte et saisir le nouveau. Vous ne pouvez ni supprimer votre propre compte, ni changer votre propre rôle. Un compte déjà utilisé (questions, classes) ne peut pas être supprimé.

## 3. Affecter les matières aux formateurs

Menu **Formateurs**, lien « Gérer les matières », puis cocher les matières que le formateur assure. Retirer une matière déjà utilisée dans une classe avec ce formateur est refusé.

## 4. Créer les mots-clés

Menu **Mots-clés**. Un mot-clé rattaché à au moins une question ne peut plus être modifié ni supprimé.

## 5. Créer les classes

Menu **Classes**, bouton « Nouvelle classe » (nom et année), puis « Gérer » :

- **Étudiants** : ajouter les étudiants. Un étudiant ne peut être que dans une seule classe par année.
- **Matières et formateurs** : ajouter une matière avec son formateur. La liste ne propose que les couples possibles (matières déjà affectées au formateur à l'étape 3).

Une classe ne peut pas être supprimée si des QCM existent pour elle.
